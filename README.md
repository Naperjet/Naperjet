# Pranjeet Sarkar

## Aerospace GNC Engineer | Flight Software | Numerical Methods

I am an aerospace engineer specializing in Guidance, Navigation, and Control (GNC), with a heavy focus on bridging the gap between high-level dynamic modeling and deterministic C++ flight software. My work centers on Software-in-the-Loop (SIL) pipelines, ensuring bit-level reproducibility and real-time performance for complex dynamical systems.

## Research & Technical Interests

- **Numerical Methods:** High-precision ODE integration, floating-point error mitigation, and zero-overhead linear algebra.
- **Aerospace GNC:** 6-DOF simulation, trajectory optimization, and stochastic estimation.
- **Flight Software:** Real-time OS (RTOS) integration, cache-optimized arithmetic, and modular C++ architecture.
